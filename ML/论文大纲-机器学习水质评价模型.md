# 第X章 基于机器学习的水质评价模型

> 论文题目：用于海洋牧场的多参数水质监测系统开发
>
> 本章对应代码目录：`ML/`
>
> 前置章节：第2章 硬件系统设计（传感器采集 DO、温度等原始数据）、第3章 水声通信（数据回传）
>
> 本章目标：利用硬件系统采集的水质参数，构建基于机器学习的自动水质评价模型，实现从"原始数据"到"水质等级"的智能判定

---

## X.1 水质评价方法概述

### X.1.1 传统水质评价方法的局限性

- 单因子评价法、综合污染指数法等传统方法依赖人工设定阈值，缺乏对参数间非线性关系的捕捉
- 海洋牧场水质评价的特殊性：目标养殖物种（大黄鱼）对水温、盐度、溶解氧有明确适宜区间
- 引入机器学习的动机：自动学习水质参数与水质等级间的复杂映射关系，提高评价的客观性和准确度

### X.1.2 机器学习在水质评价中的应用现状

- 国内外文献综述：决策树、SVM、随机森林、神经网络等在水质分类中的应用
- 现有研究的不足：特征工程不充分、模型对比不全面、可解释性不足
- 本章研究思路：从特征分析→降维→多模型对比→最优模型解析，构建完整的评价流程

## X.2 数据预处理与标签构建

### X.2.1 原始数据描述

- 数据来源：实地采集（配合第X+1章"实地采集"章节）
- 数据规模：1510条样本，7个字段（id、Depth、Temperature、Salinity、Oxygen、pH、DO_mgL）
- 原始数据字段说明：

| 参数 | 符号 | 单位 | 说明 |
|------|------|------|------|
| 深度 | Depth | m | 采样水深，0~6004m |
| 水温 | Temperature | °C | 现场水温 |
| 盐度 | Salinity | ‰ | 水体盐度 |
| 溶解氧 | Oxygen | μmol/kg | 原始传感器读数 |
| pH | pH | — | 水体酸碱度 |
| 溶解氧浓度 | DO_mgL | mg/L | 由Oxygen换算：DO_mgL = Oxygen × 0.032 |

> DO_mgL为派生特征，将传感器原始单位(μmol/kg)转换为渔业标准单位(mg/L)

### X.2.2 缺失值处理

- 采用全局中位数填补策略（`level.py` 中 `impute_numeric_with_median`）
- 选择中位数而非均值的理由：水质数据可能存在异常值（设备故障、极端环境），中位数对异常值更鲁棒

### X.2.3 水质等级标签构建

#### 基于领域知识的加权评分法

以大黄鱼养殖水质标准为依据，设计四级水质评价体系（0~3级），通过加权评分法生成标签：

**（1）单项参数等级划分**

| 参数 | 等级3（优） | 等级2（良） | 等级1（一般） | 等级0（差） |
|------|------------|------------|-------------|------------|
| DO (mg/L) | ≥5.0 | [4.0, 5.0) | [3.0, 4.0) | <3.0 |
| pH | [7.8, 8.5] | [7.0, 7.8) | [6.0,7.0)∪(8.5,9.0] | 其余 |
| 水温(°C) | [18, 24] | [15,18)∪(24,28] | [10,15)∪(28,30] | 其余 |
| 盐度 | [24, 32] | [20,24)∪(32,35] | [15,20)∪(35,38] | 其余 |

**（2）权重配置**

溶解氧对养殖生物存活影响最大，赋予最高权重：

| 参数 | 权重 | 理由 |
|------|------|------|
| DO | 0.35 | 溶解氧直接关系鱼类呼吸，低于3mg/L即无法存活 |
| pH | 0.30 | 酸碱度影响鱼类生理代谢和免疫力 |
| 水温 | 0.20 | 大黄鱼为狭温性鱼类，适宜温度区间窄 |
| 盐度 | 0.15 | 盐度变化影响渗透压调节 |

**（3）综合评价流程**

```
原始参数 → 单项等级(0~3) → 单项分数(0/60/80/100)
    → 加权平均得分 → 综合水质等级(0~3)
```

- **一票否决机制**：DO < 3 mg/L → 直接判定等级0（硬性安全底线）
- **等级映射**：得分≥95→3级，≥70→2级，≥50→1级，其余→0级

**（4）标签分布**

| 水质等级 | 样本数 | 占比 |
|---------|-------|------|
| 0（差） | 234 | 15.5% |
| 1（一般） | 290 | 19.2% |
| 2（良） | 488 | 32.3% |
| 3（优） | 498 | 33.0% |

> 标签构建代码参考：`level.py` 中 `calc_levels_for_row`、`calc_quality_level_weighted`

## X.3 特征工程

### X.3.1 数据集划分

- 训练集/测试集 = 80%/20%（1208/302条）
- 采用**分层抽样**（`stratify=y`），保证各水质等级在训练集和测试集中比例一致

### X.3.2 特征相关性分析

#### Pearson相关系数矩阵

通过计算特征间Pearson相关系数，发现以下关键关系：

| 特征对 | 相关系数 | 含义 |
|--------|---------|------|
| Oxygen ↔ DO_mgL | 1.00 | 完全正相关（派生关系） |
| Temperature ↔ pH | 0.96 | 高度正相关（海水中温度升高伴随pH升高） |
| Depth ↔ Salinity | -0.05 | 几乎无相关 |

#### Spearman相关性分析

各特征与水质等级的单调相关性（按绝对值排序）：

| 特征 | Spearman相关系数 | p值 | 显著性 |
|------|-----------------|-----|--------|
| Temperature | — | <0.001 | *** |
| DO_mgL | — | <0.001 | *** |
| pH | — | <0.001 | *** |
| ... | ... | ... | ... |

> 可视化：`散点矩阵图.png`、`水质参数相关性热力图.png`、`特征与目标相关性.png`

### X.3.3 分组PCA降维策略

#### 分组依据

基于相关性分析结果，对高相关特征分组后分别进行PCA，避免传统PCA将所有特征混合降维导致的信息损失：

```
┌─────────────────────────────────────────────────────┐
│                原始特征（6个）                        │
│  Depth  Temperature  Salinity  Oxygen  pH  DO_mgL   │
└──┬──────────┬──────────┬──────────┬─────────┬───────┘
   │          │          │          │         │
   │    ┌─────┴─────┐    │    ┌────┴────┐    │
   │    │  第2组     │    │    │  第1组   │    │
   │    │ Temp & pH  │    │    │Oxygen &  │    │
   │    │ (r=0.96)   │    │    │DO_mgL    │    │
   │    │  ↓ PCA     │    │    │(r=1.00)  │    │
   │    │PC1_temp_pH │    │    │ ↓ PCA    │    │
   │    └───────────┘    │    │PC1_oxygen│    │
   │                     │    └─────────┘    │
   │                     │                   │
   ▼                     ▼                   ▼
┌─────────────────────────────────────────────────────┐
│            降维后特征（4个）                           │
│  PC1_oxygen  PC1_temp_pH  Depth  Salinity           │
└─────────────────────────────────────────────────────┘
```

#### PCA结果

| 分组 | 原始特征 | 主成分 | 解释方差比例 | 载荷 |
|------|---------|--------|------------|------|
| 第1组 | Oxygen, DO_mgL | PC1_oxygen | 100.00% | +0.71×Oxygen + 0.71×DO_mgL |
| 第2组 | Temperature, pH | PC1_temp_pH | 97.99% | +0.71×Temperature + 0.71×pH |
| 独立 | Depth, Salinity | 保持原值 | — | — |

- 6个原始特征 → 4个特征（2个PCA主成分 + 2个独立特征）
- 分组PCA的优势：保留独立特征的物理意义，仅对高相关特征降维

> 可视化：`PCA分组可视化.png`、`PCA分组策略分析.md`

## X.4 机器学习模型构建与对比

### X.4.1 模型选型

选择7种代表性机器学习模型，覆盖线性模型、距离模型、树模型和概率模型：

| 模型 | 类别 | 特点 |
|------|------|------|
| 逻辑回归（分组PCA） | 线性模型 | 可解释性强，作为基准 |
| Gaussian Naive Bayes | 概率模型 | 假设特征独立，训练快 |
| KNN | 距离模型 | 非参数方法，直观 |
| RBF-SVM | 核方法 | 处理非线性分类 |
| 决策树 | 树模型 | 可解释性强，非线性 |
| 随机森林 | 集成（Bagging） | 减少过拟合 |
| XGBoost | 集成（Boosting） | 高性能，工业界常用 |

### X.4.2 评估方法

- **5折分层交叉验证**（Stratified K-Fold）：保证每折中各类别比例一致
- 评估指标：准确率（Accuracy）、加权F1分数（Weighted F1）
- 超参数调优：网格搜索（GridSearchCV）

### X.4.3 七模型交叉验证结果

| 模型 | 准确率均值 | 准确率标准差 | 加权F1均值 |
|------|----------|------------|-----------|
| 决策树 | 99.74% | 0.25% | 0.9974 |
| 随机森林 | 99.54% | 0.26% | 0.9954 |
| XGBoost | 99.21% | 0.26% | 0.9921 |
| KNN | 96.82% | 0.45% | 0.9682 |
| RBF-SVM | 93.91% | 1.56% | 0.9385 |
| 逻辑回归（分组PCA） | 80.66% | 2.50% | 0.8062 |
| Gaussian Naive Bayes | 80.33% | 2.30% | 0.7908 |

> 数据来源：`七个模型交叉验证结果汇总表.csv`

### X.4.4 结果分析

**（1）树模型（决策树/随机森林/XGBoost）性能显著优于其他模型**

- 决策树准确率达99.74%，标准差仅0.25%，表明模型极其稳定
- 原因分析：水质等级标签本身由阈值规则生成（`level.py`），决策树天然擅长学习这类分段规则

**（2）KNN和SVM表现中等**

- KNN（96.82%）：依赖特征空间中同类样本的聚集程度
- SVM（93.91%）：核函数能捕捉非线性边界，但标准差较大（1.56%），对超参数敏感

**（3）线性模型和朴素贝叶斯表现相对较弱**

- 逻辑回归（80.66%）：水质等级与特征间存在复杂非线性关系，线性模型难以完全拟合
- 朴素贝叶斯（80.33%）：特征独立性假设不成立（Oxygen与DO_mgL完全相关）

**（4）分组PCA对逻辑回归的影响**

- 使用分组PCA后特征数从6降至4，在保持逻辑回归性能基本不变的前提下降低了维度

## X.8 本章小结

本章完成了基于机器学习的海洋牧场水质评价模型的构建，主要工作包括：

1. **水质等级标签体系设计**：以大黄鱼养殖水质标准为依据，设计了溶解氧、pH、水温、盐度四参数加权评分法，构建了四级水质评价标签（0~3级），为监督学习提供了可靠的训练标签
2. **特征工程**：通过Pearson/Spearman相关性分析和互信息分析，发现Oxygen与DO_mgL完全相关（r=1.0）、Temperature与pH高度相关（r=0.96），据此提出了分组PCA降维策略，将6维特征降至4维
3. **多模型对比实验**：对7种机器学习模型进行了5折交叉验证，决策树以99.74%准确率位居首位，随机森林（99.54%）和XGBoost（99.21%）紧随其后，验证了树模型在规则驱动型水质评价任务中的优势
4. **决策树规则解析**：提取并分析了最优决策树的分类规则，发现其自动学习的规则与领域专家知识高度一致，证明了模型的可解释性和实用性
5. **水质数据可视化系统**：开发了基于Tkinter的桌面端可视化系统，实现了水质参数实时展示、趋势图绘制、阈值报警和运行日志记录功能

本章所构建的水质评价模型和可视化系统，可部署于第2章硬件平台的集中控制器或上位机，实现从传感器采集数据到水质等级判定的端到端智能评价。
